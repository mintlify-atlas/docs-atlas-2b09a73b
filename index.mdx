ClusterFuzz is a scalable fuzzing infrastructure that finds security and stability issues in software. Google uses ClusterFuzz to fuzz all Google products and as the fuzzing backend for OSS-Fuzz, where it has found over 27,000 bugs in Google products and 36,000+ vulnerabilities across hundreds of open source projects.

## Why ClusterFuzz?

ClusterFuzz provides an end-to-end automated fuzzing pipeline — from running fuzz targets across thousands of bots to deduplicating crashes, filing bugs, and verifying fixes.

## How it works

<Steps>
  <Step title="Deploy ClusterFuzz">
    Set up a Google Cloud project and deploy ClusterFuzz using the `butler.py create_config` and `butler.py deploy` commands.
  </Step>
  <Step title="Build your fuzz targets">
    Compile your code with sanitizer instrumentation (ASan, MSan, UBSan) and upload the build archive to Google Cloud Storage.
  </Step>
  <Step title="Configure a fuzzing job">
    Create a job definition pointing to your build bucket. ClusterFuzz automatically picks up new builds as they are published.
  </Step>
  <Step title="Monitor and triage">
    ClusterFuzz runs continuously across your bot fleet, deduplicates crashes, files bugs, and finds regression ranges automatically.
  </Step>
</Steps>
